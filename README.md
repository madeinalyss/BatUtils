# BAT Utils

A collection of utilities for RKeeper (RK7), StoreHouse, and other UCS software.

## Features

- Client management
- Various maintenance utilities
- Lightweight and fast
- Windows desktop application (.NET Framework 4.8)

## Requirements

- Windows 7 SP1 or newer
- .NET Framework 4.8

## Status

BAT Utils is currently under active development. New features and improvements are added regularly.

## Development

The source tree is organized by responsibility: UI screens live in `Views`, reusable UI elements in `Controls`, application operations in `Services`, and data objects in `Models`. Formatting and line-ending rules are defined in `.editorconfig`; contributor conventions are described in [CONTRIBUTING.md](CONTRIBUTING.md).
